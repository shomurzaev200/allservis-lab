# ALL SERVIS LAB

Экспериментальная копия [fjord-acre-sky-solar](https://github.com/shomurzaev200/fjord-acre-sky-solar).

Живой сервер `http://3.25.240.90:8080` должен оставаться на `fjord-acre-sky-solar`. Этот репозиторий не подключать к systemd `allservis`, пока вы сами не решите переключиться.

## Что изменено

- Тестовые клиенты больше не удаляются по короткому Telegram ID. Чистится только `is_demo`, и то в архив.
- Назначение, принятие, завершение и номера заявок не дублируются при двух одновременных нажатиях.
- «Баланс» клиента — это доступ. Отмена одного платежа не гасит остальные подтверждённые.
- Рестарт процесса не ставит всех мастеров онлайн. Heartbeat не снимает явный офлайн.
- Кабинет `/master` открывается кодом из карточки мастера и не показывает чужие заявки.
- Telegram offset сдвигается только после успешной обработки. Повтор того же `update_id` пропускается.
- Финансы на сервере скрыты без права `finance`. Один отзыв на заявку, оценка 1–5, в журнале есть имя и почта сотрудника.
- Диспетчерская: очередь, таймер ожидания, молчание мастера, поиск, страницы, фильтр дат, карточки на телефоне, причина отмены, заметка, цены, маршрут, фото, «заявка не найдена», прочитанные уведомления.
- Бот: вызов сейчас или на дату, повтор прошлого адреса, подтверждение клиента до начисления мастеру, проблема уходит оператору.
- Новый мастер из бота не подтверждён, пока админ не нажмёт «Подтвердить» и не отдаст код кабинета.

## Запуск на отдельной машине или отдельном каталоге

Не делать `git reset` в `/home/ubuntu/fjord-acre-sky-solar`.

```bash
cd /home/ubuntu
git clone https://github.com/shomurzaev200/allservis-lab.git
cd allservis-lab
cp /home/ubuntu/fjord-acre-sky-solar/.env .env
# BETTER_AUTH_URL должен совпадать с адресом, который открывает браузер
npm ci
npm run build
node scripts/migrate.mjs
node scripts/with-app-env.mjs ./node_modules/.bin/vite preview --host 0.0.0.0 --port 8090
```

Порт `8090`, чтобы не занять рабочий `8080`. Отдельная база безопаснее, чем общая с боем: миграция `0014_reliability.sql` меняет уникальные номера и отзывы.

HTTPS в `deploy/Caddyfile` выключен, пока нет домена. `secure: false` у cookie остаётся только для голого HTTP. С доменом и HTTPS это нужно вернуть. Пример юнита: `deploy/allservis-lab.service`. Он не установлен на текущий AWS.
